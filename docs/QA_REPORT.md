### Критические

## 7. Браузерное тестирование

- **Ширины:** 1440, 1280, 768, 390, 375 px — все экраны 4 ролей и страница входа. Горизонтальной прокрутки нет, ошибок в консоли и гидратации нет (автотест).
- **Визуально:** скриншоты «Пульса», аналитики, карточки, настроек и «Моих обращений» на 768 и 375 px просмотрены. Таблица настроек на телефоне прокручивается внутри своего блока — для админ-экрана это приемлемо.
- **Мобильный сценарий** (Pixel 7): меню, переход, действия в карточке.
- **Клавиатура:** J/K и Enter в очереди, ⌘K-поиск, Esc закрывает диалог, C — новое обращение.
- **axe (WCAG 2.1 A/AA):** 8 экранов, 0 нарушений critical/serious.
- **Производительность:** API 7–10 мс; самый большой клиентский чанк — 111 КБ gzip, всего 1,5 МБ несжатого JS по всем маршрутам.
